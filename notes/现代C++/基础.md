`int&` 与 `int*` 的区别

```C++
int x = 10;
int y = 20;

int& ref = x;   // 引用
int* ptr = &x;  // 指针

ref = 30;       // x 变成 30
*ptr = 40;      // x 变成 40

ptr = &y;       // 指针可以改为指向 y
ref = y;        // 不是重新绑定，而是把 y 的值赋给 x
```

1. `nums.push_back(40)`：在末尾添加元素

`vector` 可以理解为 Python 中的 `list`，但 C++ 的 `vector` 底层使用连续内存存储元素。

```C++
vector<int> nums = {10, 20, 30};

nums.push_back(40);
```

1. `nums.erase(nums.begin() + 1)`：删除指定位置的元素

```C++
nums.begin()       // 指向第一个元素的迭代器
nums.begin() + 1   // 指向第二个元素的迭代器
nums.erase(...)    // 删除迭代器指定位置的元素
```

由于 `vector` 的元素必须连续存放，删除中间元素后，后面的元素需要向前移动。因此删除中间元素的时间复杂度为 O(n)。

|操作|时间复杂度|
|---|---|
|`vector.push_back(x)`|摊还 O(1)|
|`vector.erase(begin())`|O(n)|
|`vector.erase(begin() + 1)`|O(n)|
|`vector.erase(end() - 1)`|O(1)|

以上以 `vector<int>` 为例，删除末尾元素不需要移动后续元素。
