## 1. 什么是“正则化”？

正则化不是某一种具体算法，而是一类手段：

$$[  
\boxed{\text{限制模型过度拟合训练数据，使模型对未见数据也能工作}}  
]$$

训练模型时，实际目标不只是让训练损失最低，还要避免模型依赖过于偶然、脆弱的特征。

可以把它理解为：

```text
没有正则化：
模型可以自由记忆训练数据中的细节

加入正则化：
限制模型，使它更倾向于学习稳定、通用的规律
```

Dropout 和 Weight Decay 都属于正则化，但作用对象不同：

$$[  
\boxed{\text{Dropout 作用于中间激活值}}  
]$$

$$[  
\boxed{\text{Weight Decay 作用于模型参数}}  
]$$

---

### 基本思想

训练时，随机将一部分**激活值设为 0**。

假设某个 token 的中间表示是：

$$[  
x=[1.2,-0.7,2.4,0.5]  
]$$

Dropout 概率：

$$[  
p=0.5  
]$$

随机 mask 可能是：

$$[  
m=[1,0,1,0]  
]$$

于是保留：

$$[  
m\odot x=[1.2,0,2.4,0]  
]$$

也就是模型每次训练都临时“关闭”部分神经元。

---

## 2.2 完整公式

现代框架通常使用 inverted dropout：

$$[  
m_i\sim\operatorname{Bernoulli}(1-p)  
]$$

$$[  
\boxed{  
y=\frac{m\odot x}{1-p}  
}  
]$$

其中：

- (p)：丢弃概率；
    
- (1-p)：保留概率；
    
- (m_i=0)：对应激活被丢弃；
    
- (m_i=1)：对应激活被保留。
    

除以 (1-p) 是为了保持期望值不变：

$$\mathbb E[y_i]
=
\mathbb E\left[\frac{m_ix_i}{1-p}\right]
=
x_i$$

例如 (p=0.5)，保留下来的值要乘以：

$$[  
\frac{1}{1-0.5}=2  
]$$

因此：

$$[  
[1.2,0,2.4,0]  
\rightarrow  
[2.4,0,4.8,0]  
]$$

虽然单次结果发生变化，但多次随机训练的期望仍接近原输入。

---

## 2.3 Dropout 为什么能够正则化？

因为模型不能假设某一个特征永远存在。

例如没有 Dropout 时，模型可能过度依赖第 3 维特征：

```text
只要第 3 维很大，就输出某个结果
```

加入 Dropout 后，第 3 维有时会被清零，模型被迫同时利用其他特征。

因此 Dropout 可以理解为：

$$[  
\boxed{\text{阻止神经元之间形成过强的共适应关系}}  
]$$

也可以近似理解成每一步训练都在使用一个略有不同的子网络。

---

## 2.4 训练和推理阶段的区别

训练时：

```python
model.train()
```

Dropout 开启，随机丢弃激活值。

推理时：

```python
model.eval()
```

Dropout 关闭，所有激活都保留。

由于训练时已经使用了 (1/(1-p)) 缩放，所以推理时直接使用：

$$[  
y=x  
]$$

不需要再乘任何系数。

因此，同一个输入在训练模式下多次运行可能得到不同输出；在推理模式下通常得到确定输出。

---

## 2.5 Transformer 中 Dropout 可以出现在哪里？

原始 Transformer 中常见的位置包括：

```text
Embedding 输出
    ↓
Attention 权重
    ↓
Attention 输出
    ↓
Residual 分支
    ↓
FFN 中间激活或输出
```

例如：

$$[  
h=x+\operatorname{Dropout}(\operatorname{Attention}(N(x)))  
]$$

或者：

$$[  
y=h+\operatorname{Dropout}(\operatorname{FFN}(N(h)))  
]$$

不过不同模型的具体放置方式并不完全相同。

## 3. 为什么现代大模型经常 Dropout 为 0？

CS336 课件给出的趋势是：

- 较早期模型经常在预训练中使用 Dropout；
    
- 较新的模型更多只使用 Weight Decay；
    
- 论文没有说明 Dropout 时，开放模型通常接近于未使用 Dropout，但闭源模型未必如此。
    

课件中的部分示例为：

|模型|Dropout|Weight Decay|
|---|--:|--:|
|Original Transformer|0.1|0|
|GPT-2|0.1|0.1|
|GPT-3|0.1|0.1|
|T5 v1.1|0|0|
|PaLM|0|可变|
|LLaMA|0|0.1|
|Qwen 14B|0.1|0.1|

这些数值来自课程课件的汇总。

现代大规模预训练通常拥有极大的训练数据集，模型未必处于传统意义上的严重过拟合状态。Dropout 引入的随机噪声还可能：

- 降低训练的确定性；
    
- 增加优化难度；
    
- 干扰模型充分利用容量；
    
- 使训练和推理的网络行为不同。
    

因此很多现代 LLM 选择：

$$[  
\boxed{\text{Dropout}=0,\qquad \text{Weight Decay}>0}  
]$$

不过这不是必须遵守的定律，而是当前模型设计中的常见经验选择。


### 4.最终知识框架

```text
正则化
│
├── Dropout
│     ├── 作用于激活
│     ├── 随机清零
│     ├── 训练时开启
│     └── 推理时关闭
│
└── Weight Decay
      ├── 作用于参数
      ├── 参数持续收缩
      ├── 通常由 AdamW 实现
      └── 训练停止后不再更新
```

核心结论：

$$[  
\boxed{  
\text{Dropout 通过随机破坏中间表示来正则化}  
}  
]$$

$$[  
\boxed{  
\text{Weight Decay 通过抑制参数规模来正则化}  
}  
]$$

$$[  
\boxed{  
\text{现代 LLM 预训练通常更依赖 Weight Decay，而非 Dropout}  
}  
]$$
