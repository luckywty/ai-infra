## 你应该完成的作业

### 第一优先级：Assignment 1 — Basics，选择性完成

Assignment 1 是后续理解推理引擎的模型基础。官方要求包括 Tokenizer、模型架构、优化器以及训练一个小语言模型。[Stanford CS336](https://cs336.stanford.edu/)

但你不必完整做完所有部分。

#### 必须完成

重点实现：

- Linear；
- Embedding；
- RMSNorm；
- RoPE；
- Multi-Head Self-Attention；
- SwiGLU；
- Transformer Block；
- 完整 Transformer LM 前向传播；
- Cross Entropy；
- 模型保存和加载；
- 单元测试。

这些内容让你真正理解：

- Tensor Shape 如何变化；
- Attention 内部如何计算；
- 模型参数如何组织；
- 哪些算子会成为推理热点；
- 后续 KV Cache 应该加在哪里。

#### 建议完成

- AdamW；
- Gradient Clipping；
- 一个最小训练循环；
- 在 TinyStories 小数据集上训练少量 Step；
- 文本生成与采样。

训练不需要追求模型质量。你只需要确认：

```
前向传播正确
→ Loss能够下降
→ 模型能够保存和加载
→ 可以完成简单自回归生成
```

#### 可以简化或跳过

- 高性能 BPE Tokenizer 完整实现；
- 大规模 Tokenizer 训练；
- OpenWebText 完整训练；
- 长时间预训练；
- 复杂学习率实验；
- 为了降低 Loss 进行大量调参。

Tokenizer 基础最好理解，但对于短期推理优化就业，其实现优先级低于 Transformer 核心模块。

### Assignment 1 最终目标

不是“完整复刻作业”，而是得到一个可以被后续 Benchmark 和 Profiler 调用的 Mini Transformer：

```
mini_transformer/
├── model.py
├── attention.py
├── rope.py
├── rmsnorm.py
├── swiglu.py
├── optimizer.py
├── generate.py
├── benchmark.py
└── tests/
```

预计投入：**20—35 小时**。

### 最高优先级：Assignment 2 — Systems，选择性深入完成

对 AI Infra 推理优化而言，Assignment 2 比 Assignment 1 更直接相关。

官方将 Assignment 2 定义为：

- 对 Assignment 1 模型和各层进行 Profiling 与 Benchmark；
- 使用 Triton 实现并优化 FlashAttention-2；
- 构建内存高效的分布式训练版本。[Stanford CS336](https://cs336.stanford.edu/)

你应该拆开处理。

#### 必须完成：Benchmark 与 Profiling 部分

重点完成：

- 模型整体 Benchmark；
- 单层和单算子 Benchmark；
- Warm-up；
- 正确的 CUDA 同步；
- 不同 dtype 测试；
- 不同 Batch Size 测试；
- 不同 Sequence Length 测试；
- PyTorch Profiler；
- 显存测量；
- FLOPs 或吞吐分析。

重点分析：

- Attention 耗时如何随序列长度变化；
- FFN 与 Attention 谁占主要时间；
- FP32、FP16、BF16 差异；
- Forward 与 Backward 耗时差异；
- Memory Bound 与 Compute Bound；
- 编译和 Kernel Launch 开销。

虽然课程作业偏训练，但你应额外增加推理实验：

- Prefill Benchmark；
- 单 Token Decode Benchmark；
- 无 KV Cache 与有 KV Cache 对比；
- 不同上下文长度的 KV Cache 占用；
- TTFT、TPOT 和 tokens/s。

这是最适合写进简历的部分。

#### 必须完成：Triton 基础部分

你不必一开始完整实现高性能 FlashAttention-2。

推荐递进顺序：

1. Triton Vector Add；
2. Triton Softmax；
3. Triton RMSNorm；
4. Triton Matmul 教程；
5. 再阅读或实现 FlashAttention 核心部分。

至少独立实现一个：

- RMSNorm；或
- Fused Softmax。

并完成：

- 与 PyTorch 参考实现的正确性比较；
- FP16/BF16 测试；
- 不同 Shape Benchmark；
- 性能曲线；
- 对性能现象的解释。

#### 加分项：FlashAttention-2

Assignment 2 要求自己用 Triton 实现 FlashAttention-2。[Stanford CS336](https://cs336.stanford.edu/)

这个任务含金量高，但难度也较高。对于 10 周路线：

- 两个月计划：理解原理、跑通官方或课程框架、完成部分实现；
- 三个月且进度顺利：尝试完整实现并通过测试；
- 不要为了完整 FlashAttention 卡住三四周，导致 vLLM 项目没有完成。

你至少需要理解：

- 为什么标准 Attention 产生大量 HBM 读写；
- Tiling；
- Online Softmax；
- 为什么不显式存储完整 Attention 矩阵；
- 重计算与 I/O 之间的权衡；
- 为什么 FlashAttention 仍然是精确 Attention。

#### 暂缓：分布式训练部分

Assignment 2 还要求实现内存高效的分布式训练。[Stanford CS336](https://cs336.stanford.edu/)

短期可以只理解：

- DDP；
- Tensor Parallel；
- All-Reduce；
- Reduce-Scatter；
- All-Gather；
- 参数、梯度、优化器状态显存；
- 通信与计算重叠。

暂时不需要完整实现：

- 分布式训练框架；
- FSDP；
- ZeRO；
- 多机训练；
- 完整分布式 Checkpoint。

这些内容更偏训练 Infra。你的时间应优先投向 vLLM、KV Cache 和 Serving。
